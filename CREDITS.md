## 5. Graceful Image Degradation

Every image component throughout Verdant Hearth includes an automatic fallback:
```html
<img
  src={dish.image}
  alt={dish.name}
  loading="lazy"
  onerror="this.onerror=null; this.src='/placeholder-dish.svg';"
/>
```
If an external image fails to resolve or if the client environment is offline, the template displays an elegant branded dark-forest and antique-gold vector placeholder (`/placeholder-dish.svg`) without breaking layout or throwing errors.
